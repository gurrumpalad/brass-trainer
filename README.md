![Android](https://img.shields.io/badge/Platform-Android-3DDC84?style=flat&logo=android&logoColor=white)

![License](https://img.shields.io/badge/License-MIT-blue.svg)

Интерактивный кросс-языковой тренажёр аппликатуры клапанов и чтения нот с листа для трубачей (труба in B♭, записанный строй). Прототип на Kotlin + Jetpack Compose с нулевыми внешними аудиобиблиотеками.

---

## Возможности и локализация

- 🌐 **Двуязычный интерфейс**: мгновенное переключение между **Русским** и **Английским** языками в настройках.
- 🎼 **Традиционная русская нотация**: при выборе русского языка названия нот отображаются с учётом классической русской терминологии октав (*До первой*, *Соль малой*, *Фа♯ малой* и т.д.).
- 🎵 **4 игровых режима**:
  - **Чтение с листа** (связка «нота → пальцы»)
  - **Ритм-режим** (бегущая нотная строка под метроном с окном попадания ±320 мс)
  - **На слух** (развитие внутреннего слуха без визуальной подсказки ноты)
  - **С настоящей трубой** (микрофонный тюнер с алгоритмом MPM, проверка интонации в пределах ±35 центов)
- 📈 **Статистика и интервальное повторение**: учёт точности по каждой ноте и «нагрев» сложных нот для эффективной тренировки.

---

## Режимы тренировки

| Режим | Что тренирует | Описание |
|---|---|---|
| 🎵 **Чтение с листа** / *Sight Reading* | связка «нота → пальцы» | На экране нота на стане — нажмите верную комбинацию клапанов (или кнопку **0 — открытая труба**). |
| 🥁 **Ритм-режим** / *Rhythm Mode* | чувство ритма и темпа | Нотная строка движется под метроном (дефолт 90 уд/мин); удерживайте аппликатуру в момент пересечения нотой золотой линии. |
| 👂 **На слух** / *Ear Training* | внутренний слух | Нота воспроизводится синтезатором, но не показывается; аппликатура подбирается на слух. |
| 🎤 **С настоящей трубой** / *Live Trumpet* | интонация и звукоизвлечение | Приложение слушает игру через микрофон, определяет частоту (MPM) и проверяет попадание в ноту. |

## Таблица аппликатур (in B♭, F♯3…C6)

Открытая труба формирует натуральный ряд …C4, G4, C5, E5, G5, C6; клапаны понижают звук (1-й на 2 пт, 2-й на 1 пт, 3-й на 3 пт).

| Понижение | Клапаны | Альтернативы |
|---|---|---|
| 0 пт (открыто) | `0` (без клапанов) | B♭5 (альт: `0`) |
| 1 пт | `2` | — |
| 2 пт | `1` | B♭4 / B♭5 (альт: `0`) |
| 3 пт | `1+2` | `3` (для A3, E4, A4, C♯5, A5) |
| 4 пт | `2+3` | — |
| 5 пт | `1+3` | — |
| 6 пт | `1+2+3` | — |

Проверка ответа использует правило подмножества: точное совпадение — верно; не является подмножеством — ошибка; частичный ввод (не все пальцы нажаты) — ожидание завершения ввода.

## Уровни сложности (Строгое расширение диапазона)

- **Уровень 1**: `C4 – G4` (До первой — Соль первой)
- **Уровень 2**: `C4 – C5` (До первой — До второй)
- **Уровень 3**: `F♯3 – C5` (Фа♯ малой — До второй)
- **Уровень 4**: `F♯3 – G5` (Фа♯ малой — Соль второй)
- **Уровень 5**: `F♯3 – C6` (Фа♯ малой — До третьей, полный диапазон)

## Архитектура и стек

- **Язык**: Kotlin 2.0
- **UI**: Jetpack Compose, Material 3, Navigation Compose
- **Аудио и анализ**: 
  - Собственный аддитивный синтезатор (`BrassSynth`) через `AudioTrack`
  - Реализация алгоритма MPM (McLeod Pitch Method) на чистом Kotlin для микрофонного тюнера без сторонних тяжелых библиотек (TarsosDSP и т.д.)
  - Векторная нотная графика через `Canvas` + шрифтовые глифы [Bravura](docs/OFL-Bravura.txt) (SMuFL, лицензия OFL 1.1)

## Сборка и запуск

```bash
./gradlew assembleDebug          # Сборка debug APK: app/build/outputs/apk/debug/
./gradlew testDebugUnitTest     # Запуск юнит-тестов
```

Требуется Android Studio (Koala или новее) и JDK 17.

## Структура проекта

```
app/src/main/java/com/trumpet/trainer/
├── TrumpetApp.kt              # Application + AppContainer (dependency container)
├── MainActivity.kt            # NavHost с динамической локализацией
├── core/
│   ├── model/                 # Valve, WrittenNote (с русской нотацией), FingeringChart, Level, AppLanguage
│   ├── audio/                 # BrassSynth (синтез трубы), AudioNotePlayer
│   ├── pitch/                 # MpmPitchDetector, MicPitchTracker (AudioRecord)
│   └── stats/                 # StatsRepository ( JSON + интервальное повторение)
├── game/                      # ViewModel-и и игровые движки
│   ├── TrainerViewModel       # логика чтения с листа и слуха
│   ├── RhythmEngine/ViewModel # движок ритм-режима
│   ├── MicViewModel           # транспозиция B♭ и анализ высоты
│   └── NotePicker             # взвешенный выбор нот по статистике
└── ui/
    ├── components/            # StaffRenderer (Bravura), ValvePad (мультитач + кнопка 0)
    ├── screens/               # HomeScreen, TrainerScreen, RhythmScreen, MicScreen, StatsScreen
    ├── localization/          # AppStrings (русский и английский словари)
    └── theme/                 # Тёмная латунная тема Material 3
```
